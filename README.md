# Bingo DataGlobal — Descargas

Instaladores oficiales de **Bingo DataGlobal**, software de bingo para eventos de **Data Global**.

## Descargar la última versión

Entra a **[Releases → Latest](https://github.com/Data-Global/DataGlobal_Bingo_Install/releases/latest)** y descarga:

| Sistema | Archivo |
|---|---|
| **Windows** | `BingoDataGlobal-Setup-X.Y.Z.exe` |
| **Mac** (chip Apple o Intel) | `BingoDataGlobal-X.Y.Z-mac.dmg` |

Después de instalar, abre el programa y escribe el **token** que te entregó Data Global.

## Actualizaciones

El programa revisa solo si hay una versión nueva cada vez que se abre:

- **Windows:** la descarga en segundo plano y se instala al cerrar el programa (o con el botón *Reiniciar y actualizar*).
- **Mac:** avisa que hay una versión nueva y abre esta página para descargarla.

## Avisos de seguridad la primera vez

- **Windows** — si aparece *"Windows protegió su PC"*: clic en **Más información → Ejecutar de todas formas**.
- **Mac** — si dice que no se puede abrir: **Configuración del Sistema → Privacidad y seguridad → Abrir de todas formas**.
